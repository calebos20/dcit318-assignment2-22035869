# DCIT318 Assignment 2 - C# OOP Demonstrations

This repository contains three C# console applications demonstrating different aspects of Object-Oriented Programming:

## Project 1: Inheritance and Method Overriding
Demonstrates how to use inheritance and override methods in derived classes.
- Base class: `Animal`
- Derived classes: `Dog`, `Cat`
- Location: `Task1_Inheritance/Program.cs`

## Project 2: Abstract Classes and Methods
Demonstrates how to use abstract classes and implement abstract methods.
- Abstract class: `Shape`
- Derived classes: `Circle`, `Rectangle`
- Location: `Task2_AbstractClasses/Program.cs`

## Project 3: Interfaces
Demonstrates how to implement interfaces to define contracts.
- Interface: `IMovable`
- Implementing classes: `Car`, `Bicycle`
- Location: `Task3_Interfaces/Program.cs`

## How to Run

Clone the repository and compile/run each console application:

```bash
git clone https://github.com/calebos20/dcit318-assignment2-22035869.git
cd dcit318-assignment2-22035869
```

Each project can be compiled and run individually using the C# compiler or Visual Studio.
